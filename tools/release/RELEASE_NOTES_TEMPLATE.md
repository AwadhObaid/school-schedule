# ما الجديد

هذا الملف قالب أولي. عدّل النص واعتمده قبل أول نشر مستقر.

- انتقال تطبيق «التوقيت المدرسي» إلى Flutter.
- إضافة «حصصي» وحالة الحصة الحالية والقادمة.
- دعم الجداول المتعددة ودوام رمضان.
- تنبيهات الجدول المدرسي وتنبيهات حصص المعلم.
- اختيار نغمة الجرس ومستوى الصوت.
- الوضع الليلي.
- النسخ الاحتياطي والاستعادة.
- التحقق من التحديثات عبر GitHub Releases.

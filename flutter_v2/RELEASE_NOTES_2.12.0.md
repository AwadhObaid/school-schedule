# التوقيت المدرسي — Flutter V2 2.12.0

## ملخص الإصدار

إصدار جديد يركز على نظام إنشاء الاختبارات للمعلم وتجهيز ورقة الاختبار الرسمية بصيغة A4.

## أهم التحديثات

### الاختبارات
- محرر اختبارات مخصص للمعلم.
- تحرير نصوص غنية واتجاه RTL.
- دعم المعادلات والرموز الرياضية والعلمية.
- أدوات إنشاء وتحرير الجداول.
- دعم دمج وتقسيم الخلايا.
- التحكم بعرض الجدول وارتفاع الصفوف والأعمدة.
- حفظ محتوى الاختبار بصيغة HTML قابلة لإعادة التحرير.

### ورقة الاختبار
- قالب A4 رسمي متعدد الصفحات.
- الشعار الرسمي والأصول البصرية المعتمدة.
- رأس وتذييل متكرران لكل صفحة.
- ترقيم الصفحات.
- دعم اسم الأستاذ والتذييل.
- تقسيم المحتوى والجداول على صفحات متعددة مع الحفاظ على ترتيب الأسئلة.

### معاينة PDF
- معاينة عمودية للصفحات.
- تمرير رأسي بين جميع صفحات الاختبار.
- تكبير وتصغير.
- ملاءمة الصفحة.
- طباعة PDF.
- مشاركة PDF.

## متطلبات ما قبل النشر

1. تشغيل `flutter pub get`.
2. تشغيل `flutter analyze`.
3. تشغيل `flutter test`.
4. بناء APK Release موقّع.
5. تثبيت APK على جهاز Android واختبار:
   - محرر الاختبار.
   - الجداول.
   - المعادلات.
   - معاينة A4 العمودية.
   - التمرير بين الصفحات.
   - الطباعة والمشاركة.
6. نشر APK مع ملف SHA-256.
